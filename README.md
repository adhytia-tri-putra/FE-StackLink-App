# StackLink Frontend

Frontend StackLink dibuat dengan React, Vite, dan Tailwind CSS.

## Fitur

- Authentication pages
- Dashboard
- Profile builder
- Link management
- Analytics
- Publishing settings
- Admin page

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment

Copy `.env.example` menjadi `.env`, lalu sesuaikan konfigurasi backend.

```env
VITE_API_BASE_URL=
VITE_DEV_PROXY_TARGET=http://127.0.0.1:5000
```
